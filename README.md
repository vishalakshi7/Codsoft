#  Task 2 – Exploratory Data Analysis (EDA)

# Objective

Perform Exploratory Data Analysis to understand the structure, distribution, relationships, and important patterns within the dataset.

# Analysis Performed

# 1. Descriptive Statistics

Used:

```python
df.describe()
```

to understand numerical variables such as Sales and other dataset attributes.

# 2. Sales by Category

Calculated total sales for each product category.

```python
category_sales = df.groupby("Category")["Sales"].sum()
```

#3. Sales by Region

Analyzed sales performance across different regions.

```python
region_sales = df.groupby("Region")["Sales"].sum()
```

# 4. Sales by Customer Segment

Analyzed sales according to customer segments.

```python
segment_sales = df.groupby("Segment")["Sales"].sum()
```

#5. Top 10 Customers

Identified customers generating the highest sales.

```python
top_customers = (
    df.groupby("Customer Name")["Sales"]
    .sum()
    .sort_values(ascending=False)
    .head(10)
)
```

#6. Top 10 Products

Identified the products with the highest sales.

# 7. Outlier Detection

Used the **Interquartile Range (IQR)** method to identify potential Sales outliers.

The IQR is calculated as:

```text
IQR = Q3 - Q1
```

Outlier boundaries:

```text
Lower Bound = Q1 - 1.5 × IQR
Upper Bound = Q3 + 1.5 × IQR
```

Records outside these boundaries were identified as potential outliers.

#  Task 4 – Customer Analysis

# Objective

Analyze customer purchasing behavior and identify high-value customers and important customer segments.

# Analysis Performed

# 1. Top Customers by Total Sales

Calculated total sales generated by each customer.

```python
customer_sales = (
    df.groupby(
        ["Customer ID", "Customer Name"]
    )["Sales"]
    .sum()
    .sort_values(ascending=False)
)
```

The top 10 customers were identified.

# 2. Customers with Most Orders

Calculated the number of unique orders for each customer.

```python
customer_orders = (
    df.groupby("Customer ID")["Order ID"]
    .nunique()
    .sort_values(ascending=False)
)
```

# 3. Average Sales per Customer

Calculated average sales generated by each customer.

```python
customer_average = (
    df.groupby("Customer ID")["Sales"]
    .mean()
    .sort_values(ascending=False)
)
```

# 4. Customer Segment Analysis

Analyzed each customer segment based on:

* Total Sales
* Average Sales
* Number of Orders
* Number of Customers

```python
segment_analysis = df.groupby("Segment").agg(
    Total_Sales=("Sales", "sum"),
    Average_Sales=("Sales", "mean"),
    Number_of_Orders=("Order ID", "nunique"),
    Number_of_Customers=("Customer ID", "nunique")
)
```

# 5. Sales by State

Identified the top-performing states based on total sales.

# 6. High-Value Customers

Used the **90th percentile** of customer sales to identify high-value customers.

Customers whose total sales were greater than or equal to this threshold were classified as high-value customers.

# 7. Customer Segment Visualization

Created a bar chart to compare total sales across customer segments.
